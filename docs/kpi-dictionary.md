# 指标字典

| 指标 | 计算口径 | 单位与解读边界 |
| --- | --- | --- |
| 原始明细行数 | 六份 CSV 的非空数据行数，保留完全相同行 | 行；不是订单数或采购件数 |
| 不同订单数 | `COUNT(DISTINCT ORDER_ID)` | 订单 ID；一个订单有多行 |
| 活跃客户数 | 不同 `CUSTOMER_ID`；月度图在每个匿名月份分别去重 | 客户 ID；跨月不能简单相加 |
| 不同物料数 | 不同 `ITEM_ID` | 匿名物料编码，不是可读品名 |
| 订单—物料组合数 | 每个不同 `ORDER_ID` 与 `ITEM_ID` 组合计一次 | 组合；同一订单内重复明细不增加 |
| 客户—物料组合数 | 每个不同 `CUSTOMER_ID` 与 `ITEM_ID` 组合计一次 | 组合，是再次出现占比的分母 |
| 再次出现的客户—物料组合 | 该组合具有至少两个不同 `REQUEST_DATE` | 组合；同日多个订单及重复行不增加 |
| 组合合计再次出现占比 | 再次出现组合数 ÷ 全部客户—物料组合数 × 100 | %；47.47%，组合多的客户影响更大；非客户留存率 |
| 客户再次出现占比 | 每位客户的再次出现组合数 ÷ 该客户全部物料组合数 × 100 | %；先逐客户计算，才能求客户中位数 |
| 客户中位数 | 对客户再次出现占比排序，取中间值；偶数位取两中间值的均值 | %；全部 238 位客户为 20.92% |
| 至少 10 单客户中位数 | 只在不同订单数不少于 10 的客户中取上项中位数 | %；134 位客户为 40.37%；10 单是描述性门槛 |
| 前 10 客户订单占比 | 订单数最高的前 10 位客户的不同订单数之和 ÷ 全部不同订单数 | %；58.96%，非收入占比 |
| 前 10 物料出现占比 | 不同订单中出现次数最高的前 10 个物料的订单—物料组合数之和 ÷ 全部订单—物料组合数 | %；2.52%，非采购数量占比 |
| 地区订单数 | 在各 `LOCATION` 中分别对 `ORDER_ID` 去重 | 地区内订单数；地区客户数差异很大 |
| 月度订单数 | 在各匿名月份中分别对 `ORDER_ID` 去重 | 匿名月的订单数；不能对应真实日历事件 |

源文件的 `PRICE_EXACT` 是**单价**；缺少数量、订单总额和货币，因此没有“采购额”或“销售额” KPI。SQL 口径见 [`sql/03_powerbi_views.sql`](../sql/03_powerbi_views.sql) 至 [`sql/06_customer_distribution.sql`](../sql/06_customer_distribution.sql)。
