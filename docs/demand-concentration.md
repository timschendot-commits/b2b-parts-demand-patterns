# 客户与物料需求集中度

本分析使用六份原始 CSV 的全部记录。指标由 [`sql/04_demand_views.sql`](../sql/04_demand_views.sql) 生成，可通过 [`scripts/export_powerbi_data.mjs`](../scripts/export_powerbi_data.mjs) 导出到本地 CSV。

## 关键发现

| 指标 | 数值 | 口径 |
| --- | ---: | --- |
| 全部不同订单 | 24,532 | `COUNT(DISTINCT order_id)` |
| 第一位客户的订单占比 | 19.58% | 4,804 / 24,532 |
| 前 10 位客户的订单占比 | 58.96% | 14,465 / 24,532；每个订单只属于一个客户 |
| 不同订单—物料组合 | 221,886 | 同一订单内的同一物料只计一次 |
| 前 10 个物料的组合占比 | 2.52% | 5,595 / 221,886 |

订单明显集中在少数客户；同时，按不同订单—物料组合衡量，物料需求分散在大量匿名物料编码上。这是**出现频次**的观察，不能推断采购件数、采购金额或库存需求。

## 如何读第二页

- “客户订单数”表示每个匿名客户关联的不同订单 ID 数。前 10 位客户图是排序后的描述，不代表客户价值排名。
- “物料出现次数”表示某物料出现在多少个不同订单中。物料 ID 是匿名编码，不具备可读的产品名称。
- “再次采购”表示同一客户与物料组合在至少两个不同匿名日期出现。47.47% 的分母是全部 73,020 个客户—物料组合，不是客户数，也不是订单数。

地区再购率暂不作为排序结论：部分地区客户数很少，例如 Central America 只有 1 位客户，比例容易受到单一客户影响。数据还缺少采购数量、订单金额、供应商、交付和库存字段，因此不能据此评估供应风险或补货策略。
